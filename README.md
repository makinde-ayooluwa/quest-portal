# 🎓 School Management System (Student Portal)

A modern, full-featured **School Management System** built with PHP and MySQL, designed to streamline student activities, academic tracking, and communication.

---



## ✨ Features

### 👤 Student Dashboard

* Personalized dashboard with stats
* Assignment tracking (submitted / pending)
* Notifications system

### 📚 Academic Management

* View results and grades
* Track assignments and submissions
* Class-based filtering

### 🔔 Notifications System

* Real-time notification tracking
* Unread notification counter

### 📅 Events System

* Upcoming school events
* Calendar-based tracking

### 🛠️ Profile Management

* Update student details
* Manage personal information

---

## 🧱 Tech Stack

* **Backend:** PHP (PDO)
* **Database:** MySQL
* **Frontend:** HTML, CSS, Bootstrap
* **Architecture:** Modular PHP structure
